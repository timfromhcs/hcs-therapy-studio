# Security policy

## Reporting a vulnerability

Report privately — do not open a public issue for anything that could expose
another user's data or disable a safety layer. Include: affected version or
commit, reproduction steps, observed behaviour, expected behaviour, and whether
the issue can leak content or bypass the crisis gate.

Until a private channel is published with the first release, report through the
repository owner (`hcsmedia`) using the contact listed on the repository profile.

## What we consider in scope

- Bypassing the deterministic crisis gate or the output guard.
- Extracting journal, message or export content that should be encrypted or
  scoped.
- Reaching the local API from another process, another browser origin, or the
  network.
- Escaping the tool sandbox (path traversal, unexpected side effect, command
  execution).
- Prompt injection that changes product behaviour rather than just text.
- Supply-chain issues in the dependency set.
- Malicious SVG or document content that executes or phones home.

## Out of scope (but still welcome as a report)

- The model producing a bad answer. That is a quality issue — open it as such,
  and only if you can include the exact prompt and settings.
- Attacks that require the attacker to already have read/write access to the
  user's Windows profile.

## Design commitments an attacker must defeat

| Layer | Guarantee |
|---|---|
| Network | The API binds `127.0.0.1`, requires a per-launch bearer token, and rejects any origin not in the allow-list. |
| Data at rest | Journal bodies and messages are AES-256-GCM encrypted; the audit table never stores content. |
| Tools | No shell, no arbitrary SQL, no unrestricted delete. Paths are confined to user-approved roots. Side effects require explicit approval. |
| Safety | The crisis gate is deterministic, runs before the model, and cannot be disabled by prompt text. |
| Generators | SVG is rebuilt from an allow-list; scene rendering is field-validated. No model-authored markup reaches the DOM. |

## Dependencies

The runtime deliberately keeps its dependency surface small: `pyyaml` and
`cryptography`, both audited and pinned in the lockfile. An SBOM is generated by
`hcs-therapy license generate`.

## Disclosure

We will state plainly what was affected, which versions, and what a user must do
— including "rotate nothing, but delete the export" where that applies. Silent
fixes are not acceptable for a local-first product that holds diary content.
